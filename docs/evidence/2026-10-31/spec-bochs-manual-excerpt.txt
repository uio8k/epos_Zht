摘录 8: master .conf.win64-vcpp 全文（官方 Win64 构建配置，无 --enable-hdaudio）
URL: https://cdn.jsdelivr.net/gh/bochs-emu/Bochs@master/bochs/.conf.win64-vcpp
--------------------------------------------------------------
#!/bin/sh

set echo

./configure --target=x86_64-windows \
            --enable-sb16 \
            --enable-ne2000 \
            --enable-all-optimizations \
            --enable-cpu-level=6 \
            --enable-3dnow \
            --enable-x86-64 \
            --enable-vmx=2 \
            --enable-svm \
            --enable-avx \
            --enable-evex \
            --enable-cet \
            --enable-fred \
            --enable-pci \
            --enable-clgd54xx \
            --enable-geforce \
            --enable-voodoo \
            --enable-usb \
            --enable-usb-ohci \
            --enable-usb-ehci \
            --enable-usb-xhci \
            --enable-busmouse \
            --enable-es1370 \
            --enable-e1000 \
            --enable-show-ips \
            --enable-debugger \
            --enable-debugger-gui \
            --disable-readline \
            --without-x \
            --with-win32 --with-rfb --with-nogui

unset echo

# Fix up all makefiles so that nmake can handle them.
for i in `find . -name Makefile`; do
  if test "$i" != "./cpu/softfloat3e/Makefile"; then
    echo Removing curly brackets in $i for NMAKE.
    mv $i $i.tmp
    sed -e 's/{/(/g' -e 's/}/)/g' < $i.tmp > $i
    rm -f $i.tmp
  fi
done

结论（2026-10-31，多源一致）:
1. Bochs 任何官方版本（至 3.1，2026-08-23 发布）均无 Intel HD Audio 设备仿真。
   证据链: master 文件树无 hdaudio 设备源码 + bochsrc.5/.bochsrc/CHANGES(2.7 至 post-3.1)/发布公告 RSS 全部 0 命中 + win64 官方构建配置无 --enable-hdaudio。
2. 此前检索快照（websearch-snapshot-20261031.log 检索 1）所称『Bochs 2.7 added Intel HD Audio device emulation / hdaudio 设备 + --enable-hdaudio』为检索摘要失实，本文件一手证据予以纠正。
3. Bochs 官方支持的声卡仿真为 SB16 / ES1370（2.7 起自 QEMU 移植 ES1370）+ PC speaker。
4. com1 mode=file 串口落盘能力属实（摘录 1），但设备层面无法与 epos 的 HDA 驱动差分。
